# Example: Simulate new transaction

Let’s use an example to explain how to simulate an arbitrary transaction on Walnut.

Suppose we want to create a new transaction simulation that will call the `increase_balance` method on the following contract deployed on the `Sepolia` network: `0x03f09656761d212cdcc05f1479c914491f6096a9396fe8a6acfb6bb2351b845c`.

Entrypoint we intend to call:

```ts
    fn increase_balance(amount: felt252)
```

**Step 1: Navigate to the Simulatio Page**

Go to [**Walnut**](https://app.walnut.dev/) and click on **"Simulate Transaction"**.

**Step 2: Fill in the Form Fields**

- **Network**: Choose `SN_SEPOLIA`, as the contract is deployed on Sepolia.
- **Sender Address**: Enter your account address.
- **Number of contract calls**: Leave it to `1`, since we are invoking a single contract.
  - **Contract address**: Enter `0x03f09656761d212cdcc05f1479c914491f6096a9396fe8a6acfb6bb2351b845c`. This will load the list of available entrypoints.
  - **Entrypoint**: List of callable contract functions will be displayed. Choose `increase_balance`.
  - **Entrypoint signature**: Displays the function signature, showing the expected input arguments for the selected function.
  - **Calldata**: The `increase_balance` function requires `1` argument named `amount` of type `felt252`. Value for `amount` can be `3`, input as encoded value `0x3`.
- **Block Number**: Optionally, specify a block number. If left blank, Walnut will use the Latest block.
- **Transaction Version**: Set to `Version 1` or `Version 3`, depending on your use case. Refer to the [**Starknet Documentation**](https://docs.starknet.io/architecture-and-concepts/network-architecture/transactions/) for guidance.

**Step 3: Run the Simulation**

Click **"Run Simulation"** and wait for the results.
