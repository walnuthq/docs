# Preparing Calldata for Walnut Simulations

Calldata is an essential component of transaction simulations, representing the input data sent to a smart contract. This section will guide you through the process of preparing and managing calldata for Walnut simulations effectively.

## Filling the Calldata in Walnut Simulation Form

For Walnut simulations, the calldata format is slightly different from typical contract interactions. Walnut simulations specifically require the following data encoded in hexadecimal format:

- Contract Address: The address of the smart contract you are interacting with.
- Function Selector: A unique identifier for the contract's entry point function. This is derived from the function's name with:

  ```bash {{title: 'bash'}}
  starkli selector <function_name>
  ```

- Number of Arguments: The count of the arguments being passed to the function.
- Call Data: The actual function arguments.

The general format for preparing calldata for Walnut simulations is as follows:

- Number of Contract Calls: The total number of contract calls you are making.
- Contract Address: The address of the smart contract being invoked.
- Function Selector: The uniquely hexadecimal identifier of the contract’s entry point.
- Number of Arguments: The number of arguments being passed to the function.
- Call Data (Contract Function Arguments): The function arguments, encoded in hexadecimal format.

All of these components are necessary for Walnut to invoke the `__execute__` entrypoint.

### Example: Constructing Calldata for Walnut Simulation

Here’s an example to help you understand how to construct the calldata for Walnut simulations:

Let’s assume you are interacting with only `1` contract deployed on `sepolia` at address:

```bash {{title: 'Contract address'}}
  0x03f09656761d212cdcc05f1479c914491f6096a9396fe8a6acfb6bb2351b845c
```

And you are interacting with a the following function:

```rust {{title: 'Starknet funciton'}}
    fn increase_balance(ref self: TContractState, amount: felt252)
```

Firstly, calculate the function selector:

```bash {{title: 'Calculate increase_balance selector'}}
    starkli selector increase_balance
```

The result is:

```bash {{title: 'increase_balance selector'}}
    0x0362398bec32bc0ebb411203221a35a0301193a96f317ebe5e40be9f60d15320
```

For the `increase_balance` function, there are `1` argument with name `amount` of type `felt252`. So the valid Call Data is:

```bash {{title: 'amount'}}
    0x5
```

The final calldata, when combined, would look like this:

```bash {{title: 'Prepared calldata'}}
  0x1
  0x03f09656761d212cdcc05f1479c914491f6096a9396fe8a6acfb6bb2351b845c
  0x0362398bec32bc0ebb411203221a35a0301193a96f317ebe5e40be9f60d15320
  0x1
  0x5
```

## JavaScript Tips for Walnut Calldata

To simplify this process, we provide a JavaScript code snippet that transforms the call’s calldata into a format that Walnut accpets. The code snippet will work for the [starknet.js](https://starknetjs.com/docs/API/) version `6.11.0`.

```javascript {{ title: 'Calldata preparation script' }}
const { RpcProvider, selector } = require('starknet')

function printCalldataForWalnut(call) {
  if (!call.calldata) {
    console.log('Error: no calldata in the call')
    return
  }

  // Process calldata
  const contractCalldata = call.calldata.map((numStr) => {
    const num = Number(numStr)
    return '0x' + num.toString(16)
  })

  // Generate complete calldata
  const calldata = [
    '0x1', // Indicates the number of contracts being executed
    call.contractAddress, // Address of the target contract
    selector.getSelectorFromName(call.entrypoint), // Function selector for the entrypoint
    '0x' + contractCalldata.length.toString(16), // Number of arguments passed to the function in hex
    ...contractCalldata, // Encoded arguments for the function
  ]

  console.log(calldata.join('\n'))
}

const main = async () => {
  // Initialize Provider
  const provider = new RpcProvider({
    nodeUrl: 'https://free-rpc.nethermind.io/sepolia-juno/', // Replace with the correct RPC URL
  })

  // Deployed Test contract address on StarkNet
  const testAddress =
    '0x03f09656761d212cdcc05f1479c914491f6096a9396fe8a6acfb6bb2351b845c'

  try {
    // Fetch the ABI of the deployed contract
    const { abi: testAbi } = await provider.getClassAt(testAddress)

    if (!testAbi) {
      throw new Error('No ABI found for the specified contract address.')
    }

    // Example call object (customize as needed)
    const call = {
      contractAddress: testAddress,
      entrypoint: 'increase_balance', // Replace with actual entrypoint name
      calldata: ['5'], // Replace with appropriate calldata
    }

    // Print the calldata
    printCalldataForWalnut(call)
  } catch (error) {
    console.error('Error:', error.message)
  }
}

main().catch((err) => console.error('Unhandled error:', err))
```

To perform the simulation, follow these steps:

### Step 1: Adjust and Run the Provided Code Snippet

You can use the provided code to generate the calldata. This script will print the calldata to the console in a format ready for use. Just run:

```bash {{title: 'Run script'}}
  node index.js
```

This will output the required calldata in the console, looking like:

```bash {{title: 'Prepared calldata'}}
  0x1
  0x03f09656761d212cdcc05f1479c914491f6096a9396fe8a6acfb6bb2351b845c
  0x0362398bec32bc0ebb411203221a35a0301193a96f317ebe5e40be9f60d15320
  0x1
  0x5
```

### Step 2: Fill in the Simulation Form

Once you have the calldata from Step 1, you're ready to run the simulation. Here's how to do it:

- Go to Walnut's Simulation Page: Navigate to [app.walnut.dev](https://app.walnut.dev) and click the "Simulate Transaction" button to open the simulation form.
- Fill in the Form Fields:

  - Sender Address: Input your account address.
  - Calldata: Paste the calldata that was printed by the script in Step 1.
  - Block Number: Optionally, specify the block number. If you leave it blank, Walnut will simulate the transaction on the latest block.
  - Chain: Chose `SN_SEPOLIA`, as contract is deployed on sepolia
  - Transaction Version: Set to 1 or 3, refer to the [Starknet documentation](https://docs.starknet.io/architecture-and-concepts/network-architecture/transactions/).
  - Click "Run Simulation" and wait for the result.
