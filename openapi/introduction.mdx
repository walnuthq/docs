# Introduction

Walnut Simulation API lets you test transactions before sending them on-chain. You can inspect state changes, gas usage, and potential errors using raw calldata, decoded calls, or an existing transaction hash.

We have two APIs:

- **[EVM Simulation API](./evm-simulation/walnut-simulation-api)** – for EVM-compatible networks
- **[Starknet Simulation API](./starknet-simulation/walnut-starknet-simulation-api)** – for Starknet transactions
